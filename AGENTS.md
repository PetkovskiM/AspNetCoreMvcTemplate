# AGENTS.md

## Repository expectations
- Keep branch scope focused.
- Do not mix future milestone work into the current branch.
- Prefer Controllers + Views over Razor Pages.
- Use standard ASP.NET Core MVC patterns.
- Prefer simple, beginner-friendly code.
- Keep Program.cs clean.
- Mention clearly whether a migration is needed or not.
- Run dotnet build after changes.
- Avoid unnecessary abstractions.
